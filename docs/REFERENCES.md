# References

The bracketed keys below are used throughout the toolkit. All URLs were opened on 2026-11-08. If a link moves, open an issue.

Terminology note: under Executive Order 14434 (29 Sep 2026), U.S. federal agencies now say "Super Intelligence (SI)" where they used to say "Artificial Intelligence (AI)". Some CISA and NIST pages have been renamed as a result (for example NIST's SP 800-53 overlay project COSAiS is now COSIS). NIST says documents it had already published were not changed. This toolkit uses "AI", which is the term in the frameworks it maps to.
