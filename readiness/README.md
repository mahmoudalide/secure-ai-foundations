# T3 - AI-Readiness Checklist for CRM and Customer-Data Platforms

| File | What it is |
|---|---|
| `AI_READINESS_CHECKLIST.md` | 43 questions in 8 sections (R1-R8), a readiness decision (R9) and a phased secure-modernization pattern |
| `readiness_checklist.csv` | The same questions as a worksheet with status, evidence and owner columns |
| `integration_inventory_template.csv` | Template for the integration inventory in section R5 |

Run the platform items once per platform and the **UC** (use case) items for each AI use case. The result feeds Gate 1 of the governance template (`../governance/APPROVAL_GATES.md`) and tells you which baseline controls (`../baseline/`) need work first.

This checklist is about the platform, not the model. A good model on a platform with shared integration accounts, clear-text credentials and no read logging is still a bad idea.
